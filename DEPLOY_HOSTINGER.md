# Publish Swaradhanu

This project is an installable Progressive Web App (PWA). It needs HTTPS for microphone access and installation.

1. In Hostinger hPanel, open **Websites → Manage → File Manager**.
2. Open your domain's `public_html` folder.
3. Upload the contents of the local `src` folder into `public_html`.
4. Open your `https://` domain. The green **Install** button appears on supported browsers; Android Chrome also offers **Install app** from its menu.

No server program or database is needed. Audio stays on the user's device.
